# شهرپلاک

پلاک ملی خودرو را می‌خواند و از روی کد ایران و حرف وسط، شهر یا شهرستان ثبت را می‌گوید. متن پیامک آمادهٔ کپی است و فقط همان شهر را اعلام می‌کند.

این سایت به پلیس راهور وصل نیست و وضعیت توقیف خودرو را حدس نمی‌زند.

```bash
npm test
npm start
```

بعد از اجرا، سایت روی `http://localhost:4173` باز می‌شود.
